# 客服回复原则

## 结构

1. 确认：复述问题与影响，让客户知道你理解了。
2. 事实：已知什么、未知什么、正在核实什么。
3. 方案：临时绕过 + 根本修复 + 预防。
4. 时间：下一次更新时间或预计完成时间。
5. 下一步：客户需要做什么、你会做什么。

## 语气

- 专业、具体、共情，不卑不亢。
- 用“我们”承担责任，用“您”尊重客户。
- 短句，避免内部术语和缩写。

## 禁用表达

- “这是正常的”
- “不是我们的问题”
- “我已经反馈了”（没有后续）
- “马上就好”（无依据）
- “系统就是这样”
- “你自己操作错了”

## 敏感场景

- 安全事件：只确认事实与保护措施，细节走安全通道。
- 退款：引用政策，说明审批链路。
- 媒体/法务：转交对应负责人，不擅自评论。
