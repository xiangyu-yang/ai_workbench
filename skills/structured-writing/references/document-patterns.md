# 常见文档结构

## 方案

1. 一页纸摘要（背景/目标/方案/收益/风险）
2. 问题与目标
3. 方案与备选
4. 实施计划（里程碑/负责人/资源）
5. 风险与应对
6. 验收标准

## 复盘

1. 结论与关键教训
2. 目标 vs 结果
3. 做对了什么
4. 没做对什么（根因，不甩锅）
5. 可复用经验
6. 改进动作（负责人/时间）

## 通知

1. 一句话结论（什么变化、何时生效）
2. 影响范围
3. 需要读者做什么
4. 时间线与联系人
5. 常见问题

## 邮件

1. 主题：动作 + 对象 + 时间
2. 第一段：目的与结论
3. 背景（最多 3 句）
4. 请求/下一步（明确谁做什么）
5. 截止时间与联系方式

## 一页纸

- 背景 1 句
- 结论 3 条
- 证据 3 条
- 风险 2 条
- 下一步 3 条
