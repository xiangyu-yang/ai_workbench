# 行动项质量规则

## 合格行动项

- 动词开头：提交、确认、修复、发布、对齐、提供。
- 单一对象：一项行动只做一件事。
- 有负责人：具体到人，不写“团队”。
- 有截止时间：绝对日期。
- 有验收标准：可判断完成/未完成。
- 有依赖：需要谁提供什么。

## 常见问题

| 问题 | 反例 | 修正 |
| --- | --- | --- |
| 无负责人 | 尽快优化登录 | 张三在 11-20 前把登录成功率提升到 99.5% |
| 无截止 | 跟进客户 | 李四 11-18 前发送报价并记录 CRM |
| 多动作 | 完成测试和上线 | 拆成“完成回归测试”“提交上线申请” |
| 不可验收 | 提升体验 | 将首屏加载降到 2s 内 |
| 假决策 | 大家觉得可以 | 王五批准，11-22 前执行 |

## 状态

- 待开始 / 进行中 / 阻塞 / 已完成 / 已取消
- 阻塞必须写阻塞原因与解除人。
