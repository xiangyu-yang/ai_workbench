# 研究质量检查清单

## 问题与范围

- [ ] 决策问题、对象、时间范围、地域明确
- [ ] 读者与用途明确
- [ ] 关键概念有定义

## 证据

- [ ] 关键结论至少两个独立来源
- [ ] 一手来源比例合理（建议 ≥40%）
- [ ] 来源日期在有效期内；过时信息已标注
- [ ] 数字有口径、单位、时间
- [ ] 区分事实、推断、假设
- [ ] 至少一个反方观点/失败情景
- [ ] 没有无法核实的“据传/业内人士”

## 推理

- [ ] 结论由证据支撑，不是先有结论再找证据
- [ ] 区分相关与因果
- [ ] 关键假设显式写出
- [ ] 竞争/监管/执行风险覆盖

## 输出

- [ ] 摘要可直接给管理层阅读
- [ ] 每个事实有引用
- [ ] 建议具体到动作/对象/时间
- [ ] 来源表完整
- [ ] 已写入工作区
