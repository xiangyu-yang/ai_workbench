# 每日股价趋势分析

## 目标

回答一个非常具体的问题：**这只股票今天/未来 1-5 个交易日更可能怎么走，关键价位在哪里，什么情况证明判断错了。**

输出必须像盘前简报，不是长期研究报告，也不是填空模板：

```text
数据状态 → 今日结论 → 关键位 → 开盘情景 → 盘中验证 → 1-5 日观察 → 催化剂/风险 → 失效条件
```

## 何时使用

- “马上开盘，今天 XX 怎么走？”
- “早盘/盘中/尾盘，这只股票现在怎么看？”
- “今天支撑阻力、开盘缺口、量价是否健康？”
- “未来 1-3 天/一周的短线趋势和情景？”
- 单只 A 股、港股、美股或 ETF 的日内执行参考。

## 不适用

- 长期内在价值、DCF、分部估值、财报深度拆解：使用 `stock-analysis` 深度研究技能。
- 全市场选股/多标的对比：先用 `stock-analysis` 的 `screen_stocks.py`，再对候选做本技能。
- 纯大盘/风格/跨市场：使用 `stock-analysis` 的 `market_overview.py`；本技能只把大盘作为个股背景。

如果用户的问题主要是“值多少钱”，不要用本技能硬凑短线结论；明确切换到长期研究。

## 标的锁定

- 只分析用户**最新消息**中的标的；不得复用历史会话或示例里的代码。
- 中文名称直接传给脚本解析；代码与名称冲突时以用户明确代码为准，并在开头写“名称 + 代码”；不确定先确认。
- 用户只说“智谱”时不要自己猜代码；脚本解析失败就说明失败，不编造。

## 数据与阶段

每轮先执行：

```text
run_skill_script
skill: 每日股价趋势分析
script: scripts/daily_trend_scan.py
args: ["--symbol","<当前标的>","--days","250","--format","markdown"]
```

需要大盘/行业背景时再执行：

```text
script: scripts/market_overview.py
args: ["--market","cn|hk|us","--days","120","--format","markdown"]
```

规则：

- 行情脚本失败最多重试一次；仍失败就说明“盘前/盘中数据未获取”，只给条件式观察清单，**禁止编造价格、量比、支撑位或涨跌幅**。
- 不调用 `read_url` / `http_request` 抓财经网页。`web_search` 仅用于新闻、公告、行业事件和催化剂，必须带来源与日期；不得用搜索结果补财务数字。
- A 股基本面只作为背景；港股/美股没有结构化财务时写“未获取”，不要编造营收、净利、ROE、现金流。
- 盘前数据可能是上一交易日收盘或集合竞价快照；必须写清楚阶段，不要把它说成“实时盘中”。
- 盘中 K 线可能未完成；量比、成交额和“地量/放量”必须标注“盘中待确认”，收盘后复核。
- 报告开头必须写：数据时间、最新日线日期、价格/昨收、阶段（盘前/盘中/收盘后）、来源。

## 今日判断框架

### 1. 缺口与位置

- 高开/平开/低开：以昨收或参考收盘为基准，结合 ATR 判断是否异常。
- 位置：在 SMA20/60/200 之上/之下、20 日区间分位、前高/前低附近。
- 缺口不是方向本身；要写“高开能否守住 R1/VWAP”“低开是否回补缺口”。

### 2. 量价与执行

- 20 日量比：当日成交量/前 20 个交易日均量；≥1.2 放量、≤0.8 缩量，盘中数据要标注未完成。
- VWAP20：价格在 VWAP 上方/下方，代表近 20 日持仓成本优势。
- 放量突破、缩量回踩、放量破位、缩量反弹分别意味着什么；不要用“主力吸筹/出货”等不可验证叙事。
- 至少给：枢轴、R1/R2、S1/S2、20 日支撑/阻力、ATR 上下界。

### 3. 趋势与动量

- 趋势：SMA20/60/200 排列、价格相对均线。
- 动量：RSI14、MACD（DIF/DEA/柱体）；超买超卖不等于立刻反转。
- 波动：ATR14；用 ATR 解释止损距离和缺口风险。

### 4. 市场背景

- 指数/行业是否同向；大盘风险偏好、汇率/利率/商品等宏观变量只在有数据时写。
- 个股 α 与市场 β 分开；不要用大盘上涨解释所有个股，也不要用个股强势忽略系统性风险。

### 5. 催化剂与新闻

- 财报、业绩预告、指引、产品发布、订单、价格调整、监管、指数调整、解禁、回购。
- 每个催化剂写日期/时间窗、来源、可能影响方向、验证信号。
- 没有可靠新闻时写“未获取”，不要用旧闻或传闻填充。

## 输出结构

除用户明确要求“一句话”外，按以下顺序输出，正文控制在 **1,800-3,000 汉字**：

1. **数据状态**：数据时间、阶段、昨收/参考收盘、当前/盘前价、缺口、量比、来源。
2. **今日结论**：偏多/偏空/震荡；置信度低/中/高；一句话说明核心矛盾。
3. **关键价位表**：枢轴、R1/R2、S1/S2、20 日支撑/阻力、ATR 上下界。
4. **开盘情景表**：高开/平开/低开；触发条件、盘中观察、失效条件；主观概率用低/中/高，不伪造精确百分比。
5. **盘中验证**：量能、VWAP、均线、行业/指数共振；明确“什么信号出现才确认”。
6. **1-5 日观察**：趋势延续/震荡/反转的条件；不要给单点“必涨目标价”。
7. **催化剂与风险**：带日期/来源；至少一个反方风险。
8. **失效条件与数据缺口**：价格/量能/事件；缺失数据写“未获取”。
9. **免责声明**：只写一次，简短。

不要输出完整 DCF、三张财务报表、8 期财务长表或长期估值模板；这些属于 `stock-analysis`，会稀释当日判断。

## 质量门槛

- 开头有真实数据时间与阶段；盘前、盘中、收盘后不能混写。
- 每个关键位来自脚本或明确公式；不得凭感觉写“支撑 350”。
- 量比口径写清“当日成交量/前20日均量”；盘中标注未完成。
- 今日结论必须能落到价格/量能/事件的可验证条件，不写“注意风险”“谨慎观望”就结束。
- 至少一个反向情景和失效条件；不承诺收益。
- 新闻/公告有来源与日期；财务数字不来自网页。
- 数据不足时，宁可写“无法判断”，不要生成看似完整的空模板。
- 结尾只保留一次“不构成投资建议”。
