# 隔夜新闻、财报与催化剂

## 每日开盘前检查

1. 公司公告/交易所披露：财报、预告、重大合同、回购、减持、停牌。
2. 行业事件：价格、订单、政策、竞争格局、供应链。
3. 宏观：利率、汇率、商品、指数期货、重要经济数据。
4. 市场情绪：同行业龙头、指数期货、风险资产。

没有可靠来源就写“未获取”，不要用旧闻或社交媒体传言填充。

## 来源纪律

- 官方公告/交易所披露优先于媒体转述。
- 每条信息写日期、来源、原文位置；区分“事实”“媒体解读”“我们的推断”。
- 同一事件尽量两个来源；单一来源要标注。
- 不用新闻补财务数字；财务仍来自结构化接口。
- 注意时区：港股/A 股/美股的“盘前”不同，财报日期可能对应不同交易日。

## 影响评估

| 事件 | 需要判断 |
| --- | --- |
| 财报/指引 | 超预期还是符合？现金流和指引是否恶化？ |
| 产品/订单 | 是否改变收入/利润假设？可验证的交付节点？ |
| 价格/批价 | 对毛利率和渠道库存的影响？ |
| 政策/监管 | 是正式文件还是传闻？执行时滞？ |
| 解禁/指数 | 一次性资金冲击还是基本面变化？ |
| 并购/分拆 | 对价、商誉、协同、监管条件？ |

## 当日输出

- 催化剂必须写时间窗和验证信号，不能只列事件标题。
- 至少一个负面风险或反方情景。
- 说明“哪些已经反映在价格中”，避免把已知利好当新增利好。
- 如果无法确认事件是否发生，写“待核验”，不要写“已确认”。
