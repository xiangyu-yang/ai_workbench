# 财务质量与舞弊风险检查

## 使用时机

当公司出现以下任一信号时，必须读取本清单并在报告中单独写“财务质量/反方观点”：

- 利润增长明显快于经营现金流；
- 应收账款、存货、合同资产增速远高于收入；
- 经营现金流长期低于净利润；
- 频繁并购、关联交易、资本化研发/在建工程；
- 审计意见非标、审计师更换、财务总监离职；
- 大股东质押、占用、减持或高比例关联采购。

## 一、收入质量

| 检查 | 公式/口径 | 预警 |
| --- | --- | --- |
| 应收账款增速 / 收入增速 | 期末应收 / 期初应收 - 1 | 连续 >1.3 且现金流弱 |
| 应收周转天数 | 平均应收 / 收入 × 365 | 持续上升 |
| 合同负债/预收 | 环比变化 | 大幅下降可能订单转弱 |
| 收入/销量/价格拆分 | 量×价×结构 | 只靠提价或并表 |
| 关联收入占比 | 关联销售 / 总收入 | 高且毛利率异常 |
| 渠道库存 | 经销商库存/终端动销 | 压货、退货政策 |

## 二、利润质量

- 扣非净利润 / 归母净利润：长期 <0.8 要拆非经常性损益。
- 政府补助、投资收益、公允价值变动、资产处置收益占比。
- 研发资本化率、在建工程转固、折旧年限是否突变。
- 毛利率显著高于同业且无法用产品/品牌/成本解释。
- 销售费用、研发费用资本化或费用递延。
- 股权激励费用、可转债稀释是否被忽略。

## 三、现金流质量

- 经营现金流 / 净利润（OCF/NI）：连续 3 年 <0.7 需警惕。
- 自由现金流 = OCF - CapEx；长期为负且靠融资维持。
- 收现比 = 销售商品收到现金 / 营业收入。
- 现金流与利润的差异拆解：应收、存货、应付、预收、一次性税项。
- 把“经营活动现金流”与“融资现金流”混用会掩盖真实造血能力。

## 四、资产负债表与表外

- 有息负债、短债/现金、净负债/EBITDA、利息覆盖。
- 受限资金、存贷双高、应收账款保理、供应链金融。
- 对外担保、诉讼、回购承诺、明股实债、永续债。
- 少数股东权益与少数股东损益是否匹配。
- 商誉/无形资产占净资产比例、减值测试假设。
- 租赁负债、养老金、环境修复等表外义务。

## 五、治理与关联方

- 大股东持股、质押比例、减持计划、资金占用。
- 关联采购/销售定价是否公允；关联方是否为公司输血。
- 审计委员会独立性、审计师任期与意见类型。
- 历史上是否频繁变更主业、财务总监、审计机构。
- 高管薪酬与 ROE/现金流/股价考核是否一致。

## 六、红旗分级

| 级别 | 例子 | 报告处理 |
| --- | --- | --- |
| 高 | 非标审计意见、资金占用、存贷双高、现金流长期背离 | 降低评级/置信度，列为失效条件 |
| 中 | 应收/存货增速快、资本化上升、关联交易增加 | 要求补充证据，做敏感性 |
| 低 | 单季波动、一次性收益 | 说明并剔除后看主业 |

## 七、输出要求

- 至少列 3 条支持 thesis 的证据和 3 条反证。
- 对每个红旗写“需要什么数据才能排除”，不要只写“关注风险”。
- 财务数据缺失时写“未获取”，不得用“约/估算”补齐。
- 结论区分：已证实事实、合理推断、待验证假设。
