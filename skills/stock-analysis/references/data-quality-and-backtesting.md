# 数据质量、时点与回测纪律

## 数据质量检查

| 检查 | 方法 | 处理 |
| --- | --- | --- |
| 时效 | 最新交易日/报告期与当前日期差 | 超过阈值写“可能延迟/停牌” |
| 完整 | 关键字段是否 None/0/空 | 写“未获取”，不补猜 |
| 口径 | 累计/单季、复权/不复权、币种、单位 | 在表头注明 |
| 一致 | 同一指标跨源差异 >5% | 列两源并解释 |
| 异常 | 单日量/价极端值、除权跳变 | 检查公司行动/停牌 |
| 幸存者偏差 | 只看到当前上市股票 | 回测需含退市/并购样本 |
| 前视偏差 | 使用了当时尚未公布的数据 | 按公告日而非报告期对齐 |
| 过拟合 | 参数/样本反复调优 | 样本外、滚动验证、基线对比 |

## 时点（Point-in-Time）

- 财报按**公告日**入库，而不是报告期末日；回测只能使用当时已知数据。
- 一致预期、评级、目标价要保存发布日期与版本。
- 复权价格用于收益计算，不用于“当时价格”展示。
- 指数成分、行业分类、退市样本要使用时点快照。
- 修改历史数据必须留版本，不允许覆盖回测输入。

## 回测最低要求

1. 明确 universe、调仓频率、交易成本、滑点、停牌/涨跌停处理。
2. 样本内/样本外分开；至少一个未参与调参的时期。
3. 与等权/市值加权/行业中性基线比较。
4. 报告年化收益、波动、最大回撤、Sharpe、换手率、容量。
5. 不把单次回测收益当未来预期；不做幸存者偏差选样。
6. 参数敏感性：核心参数 ±20% 不应让结论完全反转。

## 当前股票技能的边界

- 行情来自公开接口，可能有延迟、复权差异和字段缺失；
- A 股财务来自公开 F10，报告期累计口径，不等于单季；
- 港股/美股没有结构化财务，财务字段写“未获取”；
- 技能输出是研究辅助，不是回测平台，不承诺策略收益；
- 任何“历史胜率/年化收益”如果没有真实回测输入，不得写入报告。

## 报告写法

在“数据与来源”中写：

```text
行情截止：YYYY-MM-DD；财报截止：YYYY-MM-DD；公告日：YYYY-MM-DD
复权：前复权/不复权；币种：CNY/HKD/USD；单位：亿元/百万股
缺失字段：...
```

结论中区分：

- 事实：工具/公告直接返回；
- 推断：基于事实的合理演绎；
- 假设：情景模型输入，需标注；
- 预测：条件概率，不是承诺。
