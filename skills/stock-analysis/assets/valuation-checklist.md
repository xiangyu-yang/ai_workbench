# 估值与预测检查清单

## 数据与口径

- [ ] 股价、财报、指引、行业数据都有日期
- [ ] 行情是收盘/盘中；财报是累计还是单季
- [ ] 复权方式、币种、单位、股本口径一致
- [ ] 数据源冲突已列示并解释
- [ ] 净债务/少数股东/投资资产没有遗漏
- [ ] 关键数字有一手来源

## 行业与财务质量

- [ ] 已选择行业匹配的 KPI/估值方法
- [ ] 已检查应收/存货/现金流/关联交易/审计红旗
- [ ] 至少一条反方证据和一条可验证信号

## 估值

- [ ] 至少两种方法
- [ ] DCF 的 FCF 与折现率口径匹配
- [ ] WACC > 永续增长
- [ ] 敏感性分析（WACC/增长）
- [ ] 反向 DCF 隐含增长与历史/行业对比
- [ ] 周期股用正常化利润
- [ ] 相对估值同业可比

## 预测

- [ ] 三情景概率合计 100%
- [ ] 给出了催化剂时窗、验证信号和失效条件
- [ ] 没有真实回测输入时，未写历史胜率/年化收益
- [ ] 盘中/延迟数据已标注
- [ ] 每个情景有触发条件与目标区间
- [ ] 给出期望值、下行风险、置信度
- [ ] 明确时间维度
- [ ] 写出失效条件
- [ ] 至少一个反方观点

## 合规

- [ ] 不承诺收益
- [ ] 不提供内幕/操纵建议
- [ ] 有免责声明
- [ ] 区分事实、推断、预测
