# 估值与预测检查清单

## 数据

- [ ] 股价、财报、指引、行业数据都有日期
- [ ] 币种、财年、股本口径一致
- [ ] 净债务/少数股东/投资资产没有遗漏
- [ ] 关键数字有一手来源

## 估值

- [ ] 至少两种方法
- [ ] DCF 的 FCF 与折现率口径匹配
- [ ] WACC > 永续增长
- [ ] 敏感性分析（WACC/增长）
- [ ] 反向 DCF 隐含增长与历史/行业对比
- [ ] 周期股用正常化利润
- [ ] 相对估值同业可比

## 预测

- [ ] 三情景概率合计 100%
- [ ] 每个情景有触发条件与目标区间
- [ ] 给出期望值、下行风险、置信度
- [ ] 明确时间维度
- [ ] 写出失效条件
- [ ] 至少一个反方观点

## 合规

- [ ] 不承诺收益
- [ ] 不提供内幕/操纵建议
- [ ] 有免责声明
- [ ] 区分事实、推断、预测
