# 投标策略手册

## 评审门

1. **资格门**：营业执照、资质、案例、财务、法务；不满足直接放弃或找联合体。
2. **合规门**：强制条款逐条覆盖；任何“不满足”需书面澄清。
3. **技术门**：架构、集成、安全、迁移、运维、SLA。
4. **商务门**：报价、付款、履约、违约、知识产权。
5. **交付门**：团队、排期、验收、培训、售后。

## Win Themes

- 每个主题回答：客户最痛什么 → 我们凭什么 → 证据是什么 → 量化价值。
- 3-5 个即可；不要写成公司介绍。
- 证据优先：案例、基准、POC、第三方认证。

## 响应写法

- 理解：复述客户要求与场景。
- 方案：具体怎么做，含架构/流程/角色。
- 证据：案例、数据、认证、团队。
- 交付物：客户会收到什么，何时。

## 常见失分

- 复制模板，不回应具体需求。
- 强制项漏答或答非所问。
- 过度承诺，交付不可行。
- 报价与方案范围不一致。
- 忽视招标文件的格式/页数/签章要求。
