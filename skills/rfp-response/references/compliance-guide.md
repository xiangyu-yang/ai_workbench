# 合规矩阵填写规范

## 字段

| 字段 | 说明 |
| --- | --- |
| ID | 与招标文件条款编号一致；无编号则 R-001 |
| Requirement | 原文要求，不改写 |
| Mandatory | mandatory / optional / clarification |
| Category | 技术/商务/法务/安全/交付 |
| Response | 满足 / 部分满足 / 需澄清 / 不满足 |
| Section | 响应文件章节 |
| Owner | 负责人 |
| Evidence | 案例/文档/认证/承诺 |
| Status | 未开始/进行中/已评审/已确认 |

## 规则

- 强制项不得空白；不满足必须写澄清或偏离说明。
- “部分满足”要写清边界与替代方案。
- 证据必须可附；不要只写“公司实力强”。
- 每条需求只有一个负责人。
- 评审后锁定版本，变更走变更记录。
